## Local verification evidence

The 16 unique actual public-route cases passed directly with no retries/skips: signup/reset × desktop/mobile × light/dark × normal/reduced motion. The coordinator inspected all 96 state screenshots through contact sheets, sampled all 16 natural recordings, and opened full-size mobile-light signup and desktop-dark reset failures. Canonical Buttons reference captures cover all four viewport/theme combinations; desktop Form fields references show the approved inline error styling. Teacher/student-specific roles are n/a on these shared unauthenticated pages.

Each deferred case proves one resend at a time, truthful inline HTTP failure, accepted-request acknowledgement, removal of old success, exclusion of verification overlap, original code input/value/caret/scroll retention and restored native keyboard activation focus. A deliberate background pointer action cancels focus return. Resend targets grow from the measured 20px baseline to at least 44px using the existing Button. Initial native disabling lost focus to BODY; a bounded focus-ownership repair passed the strengthened real-browser matrix and 31 focused unit tests. Network/unmount/email-owner/newer-notice cases have unit coverage.

All 64 POST requests in the final matrix were intercepted synthetic responses, with zero backend/email writes. Expected failed-resource console messages match only the injected endpoint/status; unexpected console and JavaScript errors are zero. Local Event Timing observations use the same passive 16ms-threshold observer as the baseline; the exercised sequences differ, so no production INP or numerical latency-improvement claim is made. Baseline false-success/overlap proof, failed harness-authoring attempts, focus regression and final screenshots/recordings remain in the chat artifacts. The native-control registry removes the migrated signup control and decreases reset's legacy count, preserving the remaining Back-to-login exception.
