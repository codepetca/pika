## Rules

- The implementation commit must be the commit actually rendered.
- A baseline capture does not become current evidence after the implementation
  changes; refresh it or label the temporal mismatch.
- Open Design can organize and compare evidence, but the repository and running
  product remain authoritative.
- Do not claim product-wide coverage from a representative matrix.
