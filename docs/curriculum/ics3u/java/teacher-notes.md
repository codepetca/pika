## Teaching details

- A program to calculate a student average needs marks, calculation instructions, and a way to display the result. Students do not need to write it today.
- The print statement illustrates syntax. It belongs inside a method in a complete program and is not a standalone runnable program.
- CodeHS offers several Java templates. Before the next lesson, check whether the classroom starter uses a main method or a CodeHS run method. Retain its class name.
- Main.java and Main.class illustrate one simple class. Larger programs can generate many class files. Online IDEs may hide those files.
- JVM execution can include interpretation and just-in-time compilation. Avoid describing it as only an interpreter.
- Portability requires compatible JVM versions, libraries, and platform dependencies.
- The original browser/JVM slide describes old Java applets. Modern browsers do not bundle that plugin. Online Java editing does not imply applet execution.

## Discussion answers

1. Source code is the written program text. Syntax is the set of rules that text must follow.
2. The compiler produces bytecode in class files.
3. The JVM executes Java bytecode.
4. Yes. A program can follow the language rules and still calculate or display an incorrect result.
